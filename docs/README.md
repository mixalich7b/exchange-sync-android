# Документация для разработчика

Этот каталог объясняет текущее устройство Exchange Sync для разработчиков и
сопровождающих проект. Начните с нужного вопроса; подробные правила находятся
на тематических страницах.

## Куда перейти

| Что нужно понять или сделать | Документ |
|---|---|
| Понять границу продукта, модули и хранение данных | [Архитектура](architecture.md) |
| Разобраться в настройке профиля, Save и повторной проверке | [Подключение](connection.md) |
| Проверить устройство mTLS, доверия CA, redirects и HTTP-сеансов | [Транспорт](transport.md) |
| Проследить полный и incremental sync, checkpoints и восстановление | [Синхронизация календаря](calendar-sync.md) |
| Понять перенос приглашений, участников и повторяющихся событий | [Представление событий](event-mapping.md) |
| Разобраться в ownership, пакетах записи и очистке календаря | [Calendar Provider](calendar-provider.md) |
| Сравнить Sync Now, Cancel, Disable; понять retries и permissions | [Фоновая синхронизация](background-sync.md) |
| Собрать логи и расследовать ошибку | [Диагностика](diagnostics.md) |
| Найти поля логов, лимиты и правила раскрытия данных | [Справочник диагностики](reference/diagnostic-fields.md) |
| Изменить или воспроизвести схемы | [Схемы](diagrams/README.md) |
| Подготовить окружение, собрать и проверить приложение | [Инструкции репозитория](../AGENTS.md) |

Для первого знакомства: **архитектура → подключение → синхронизация календаря**.
Для расследования сбоя начните с диагностики и переходите к нужной подсистеме.

## Поддержание актуальности

Перед архивированием OpenSpec change сопоставьте затронутые страницы с итоговой
реализацией и основными спецификациями. Удалите устаревшие утверждения и не
описывайте запланированное поведение как реализованное.

У каждого подробного правила должна быть одна основная страница; остальные
документы ссылаются на неё. Числовые ограничения приводятся рядом с правилами,
которые они ограничивают. При изменении схемы обновляйте её изображение вместе
с исходником по [инструкции](diagrams/README.md).
