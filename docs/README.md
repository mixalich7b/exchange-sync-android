## Поддержание актуальности

Перед архивированием OpenSpec change сопоставьте затронутые страницы с итоговой
реализацией и основными спецификациями. Удалите устаревшие утверждения и не
описывайте запланированное поведение как реализованное.

У каждого подробного правила должна быть одна основная страница; остальные
документы ссылаются на неё. Числовые ограничения приводятся рядом с правилами,
которые они ограничивают. При изменении схемы обновляйте её изображение вместе
с исходником по [инструкции](diagrams/README.md).
