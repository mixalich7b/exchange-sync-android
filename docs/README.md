# Документация для разработчика

## Назначение

Этот каталог описывает текущее реализованное состояние Exchange Sync для
разработчиков и сопровождающих проект. Это не руководство пользователя и не
перечень будущих возможностей приложения.

## Источники истины

- [`openspec/specs/`](../openspec/specs/) содержит нормативные требования к
  принятому поведению системы. При расхождении со справочной документацией
  приоритет имеет OpenSpec.
- `docs/` объясняет текущее устройство и поведение системы в форме, удобной для
  разработчика.
- [`openspec/changes/archive/`](../openspec/changes/archive/) сохраняет
  исторический контекст, рассмотренные альтернативы и решения завершённых
  изменений. Архив не является актуальным описанием всей системы.
- Production-код определяет конкретные детали реализации в пределах принятых
  требований.

## Документы

- [Архитектура](architecture.md) — реализованная граница продукта, модули,
  зависимости, композиция и основные потоки данных.
- [Настройка подключения](connection.md) — профиль, проверка соединения,
  Android KeyChain, TLS/mTLS, ActiveSync probe, хранение и ошибки.

Команды сборки и проверки, требования к окружению и процесс разработки
поддерживаются в [`AGENTS.md`](../AGENTS.md).

## Поддержание актуальности

Непосредственно перед архивированием каждого OpenSpec change необходимо
сопоставить затронутые документы с итоговой реализацией и основными
спецификациями, обновить их до состояния после change и удалить устаревшие
утверждения. Обязательный порядок закреплён в [`AGENTS.md`](../AGENTS.md).
