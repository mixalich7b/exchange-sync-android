# Exchange Sync

Exchange Sync — приложение для Android, предназначенное для синхронизации
календаря с частным сервером Microsoft Exchange. Приложение самостоятельно
подключается к серверу по протоколу Exchange ActiveSync и не использует
встроенную в Android интеграцию с учётными записями Exchange.

## Основные возможности

- Односторонняя синхронизация основного календаря: с сервера Exchange на
  устройство Android. Изменения на устройстве не отправляются обратно на
  сервер.
- Сохранение всей истории событий, которую предоставляет сервер, и всех
  будущих событий.
- Перенос напоминаний из Exchange в системный календарь Android.
- Периодическая синхронизация в фоновом режиме.
- Системное уведомление, если возникает постоянная проблема, требующая
  действий пользователя.
- Один профиль подключения с адресом электронной почты, именем пользователя
  в формате `domain\login`, адресом сервера и клиентским сертификатом.

## Безопасное подключение

Соединение с Exchange выполняется по HTTPS на порту 443 с взаимной
TLS-аутентификацией (mTLS). Пользователь выбирает клиентский сертификат из
сертификатов VPN и приложений, установленных в Android; закрытый ключ не
копируется в приложение.

Приложение доверяет одновременно:

- корневому и выпускающему сертификатам частного удостоверяющего центра,
  добавленным в локальную сборку приложения;
- системным удостоверяющим центрам Android — например, когда сервер использует
  сертификат Let's Encrypt.

Сертификаты частного удостоверяющего центра не требуется добавлять в системное
хранилище устройства.

## Требования и распространение

- Android 16 (API 36).
- Сервер Microsoft Exchange с поддержкой Exchange ActiveSync, HTTPS и
  аутентификации по клиентскому сертификату.
- Установка приложения вручную из APK; публикация в Google Play не
  предполагается.

## Статус проверки

Server-backed checklist успешно пройден вручную на Xiaomi 17 с Android 16 и
реальным Exchange Server. Проверены HTTPS/mTLS и ActiveSync, синхронизация через
настоящий Calendar Provider и фактическое 15-минутное исполнение periodic work
через WorkManager. Автоматический набор проверок остаётся локальным и не
подключается к устройству или серверу.

## Локальная сборка

Для сборки нужны JDK 21 и Android SDK Platform 36. Укажите путь к SDK в
неотслеживаемом файле `local.properties`, например:

```properties
sdk.dir=/absolute/path/to/Android/sdk
```

Сертификаты частного УЦ размещаются локально в
`infrastructure/src/main/assets/tls/`. Каталог целиком игнорируется Git;
допускаются X.509-сертификаты в PEM- или DER-кодировке. Закрытые ключи и
клиентские сертификаты в проект помещать нельзя. Если каталог отсутствует,
приложение всё равно собирается и использует системное хранилище доверия
Android, но подключение к серверу частного УЦ завершится понятной ошибкой.

Основные команды:

```shell
./gradlew test
./gradlew lintDebug
./gradlew :app:assembleDebug
./gradlew verifyBootstrap
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`.
